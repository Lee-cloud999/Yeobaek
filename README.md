# 여백

단어, 문장, 문단을 가볍게 기록하는 PWA 웹앱입니다.

## GitHub Pages
저장소 Settings → Pages → Build and deployment → Deploy from a branch에서
`main` / `/(root)`를 선택하면 됩니다.

현재 버전은 localStorage 저장 방식입니다.
Firebase 동기화와 전체 백업/복원은 다음 단계에서 연결합니다.
